Game guide

Salad Bowl, Fishbowl, Celebrity.

Different names, same brilliant idea: guess the same pool of names several times while the clues get harder.

Are Salad Bowl, Fishbowl and Celebrity the same game?

They are commonly used as names for the same family of party game. The exact house rules can vary, but the central structure is consistent: players contribute names or words to a shared pool, teams alternate timed guessing turns, and the same pool is reused across multiple rounds with different clue restrictions.

When the pool is specifically made up of famous people, many groups call it Celebrity or Celebrities. When the focus is the container full of slips, Salad Bowl and Fishbowl are common names.

Celebrity Salad's versionThe app focuses on celebrity names and uses three classic rounds in this order: Describe It, One Word and Act It.

How to play Salad Bowl

  1. Make a shared pool. Every player contributes a few names. Traditionally these go on folded slips of paper in a bowl.
  2. Split into teams. Two teams alternate throughout the game.
  3. Set a timer. Each clue-giver has a limited turn to get through as many names as possible.
  4. Guess until the bowl is empty. Every correct answer scores a point.
  5. Put everything back. Shuffle the same names and play the next round with stricter clue rules.

The classic three-round format

Describe It

Use normal spoken clues, but do not say any part of the answer. The aim is to get through as many names as possible before time runs out.

One Word

Every name returns. This time the clue-giver gets one clue word per celebrity. Because everyone has already heard the pool once, memory starts doing some of the work.

Act It

The same names return for a final time, but the clue-giver cannot speak. Gestures and acting have to do everything.

Why do different groups remember different rules?

Salad Bowl is often passed from group to group rather than learned from one official rulebook, so variations are normal. Some groups swap the order of One Word and Act It. Some allow gestures during spoken rounds. Others add penalties for passing or include extra rounds.

There is no problem with house rules as long as everyone agrees before the timer starts. For an app, though, consistency matters, so Celebrity Salad uses one clear ruleset and keeps the game moving without penalty bookkeeping.

What should go in the bowl?

If you are playing the Celebrity version, use famous people and recognisable characters. If you prefer a broader Salad Bowl game, you can include films, places, objects, sayings or inside jokes as well.

Celebrity Salad deliberately centres on famous names because that gives the game a strong shared reference point and makes the later acting round easier to read.

Why reuse the same names?

Repeating the pool is what turns the game from ordinary guessing into something more strategic. In the first round, players learn the full set. In the later rounds, a single word or tiny gesture can work because the answer has already appeared before.

The mistakes also become part of the shared memory. An awkward clue from Round One can become the exact thing a teammate remembers in Round Three.

Paper bowl or app?

Paper is simple and works anywhere, but it does create small jobs: handwriting names, folding slips, finding a timer, keeping scores and making sure guessed names return correctly for the next round.

Celebrity Salad keeps the traditional same-room experience while handling those jobs on one iPhone. Players still invent the names and give the clues. The app just keeps the Salad organised.
