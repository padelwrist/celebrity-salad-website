How to choose good Celebrity game names

The best name pool is not simply a list of the 100 most famous people in the world. Celebrity Salad works better when the room has a shared chance of recognising the answers, but still has to think creatively about how to describe and act them.

A useful rule is to mix mostly familiar names with a smaller number of curveballs. Think about the actual people playing: a football-heavy group can handle more players and managers, while a family game may work better with film, music and characters that cross generations.

A balanced SaladAim for roughly 60% easy names, 30% medium names and 10% wildcards. The wildcard should be funny or surprising, not impossible.

Five tips for a better name pool

  1. Think room first. A name is only good if enough players can recognise it.
  2. Mix generations. Avoid a pool that only one age group understands.
  3. Choose people with hooks. Distinctive jobs, voices, roles or mannerisms make later rounds more fun.
  4. Do not overuse one category. Twenty footballers in a row can make the game repetitive.
  5. Let players surprise each other. The best games contain names nobody expected but everyone somehow knows.

How many names should each player add?

Celebrity Salad lets the host choose how many submissions each player contributes. Smaller groups can add more names per person; larger groups can add fewer so the rounds do not become too long.

As a starting point, two or three names each works well for a bigger party, while four or five each gives a small group a fuller Salad.
