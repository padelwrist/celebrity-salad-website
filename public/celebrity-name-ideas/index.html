How to choose good Celebrity game names

The best name pool is not simply the 100 most famous people in the world. Celebrity Salad works better when most of the room recognises the answers, but still has to think creatively about how to describe, reduce and act them.

A useful starting mix is mostly familiar names, a smaller group of medium-difficulty choices and a few wildcards that are funny rather than impossible.

Five tips for a better name pool

  1. Think room first. A name is only useful if enough players can recognise it.
  2. Mix generations. Avoid a pool that only one age group understands.
  3. Choose people with hooks. Distinctive jobs, voices, roles or mannerisms make later rounds better.
  4. Do not overload one category. Twenty footballers in a row can make the game repetitive.
  5. Let players surprise each other. The best Salads contain names nobody expected but everyone somehow knows.

How many names should each player add?

Celebrity Salad lets the host choose between two and five submissions per player. Larger groups usually work better with two or three names each; smaller groups can use four or five for a fuller Salad.
